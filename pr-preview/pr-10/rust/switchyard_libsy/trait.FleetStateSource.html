Expand description

Produces one coherent FleetSnapshot synchronously.

Implementors do no network I/O in snapshot; any external fact producer updates its current snapshot outside the routing request path, and the routing Algorithm reads it here as a single immutable view. The snapshot is returned as an Arc so a source can hand out a shared immutable snapshot without cloning the whole fleet on every routing decision.
