- **Harness runs abort on the second turn.** `task_agent` with `model=direct-google-gemini-3.1-flash-lite` (and 3.5) completed the first turn — `usage_events` records 69.4k–69.9k prompt tokens, `tool_calls_count=0` — then every tool-using task failed with `Error code: 503 - backend temporarily unavailable`. Reproduced 5/5 attempts (t1 and t5, both Lite models, spaced ≥70 s). A trivial single-turn prompt on the same alias succeeds, so the alias is reachable and the failure is turn-count/throughput dependent.
- **The override is honoured.** A control call with `model=direct-openrouter-flint-v1-0-free` reached that upstream and returned its model-specific grammar error, so `model=` does select the named alias for the sub-agent; the sub-agent's own turns are the 69.8k-token rows.

### Attribution

The blocker is provider throughput, not model quality: the harness's per-turn context (~69.8k tokens) multiplied by the turns a tool-using task needs exceeds the candidate's per-minute input budget, and the harness does not throttle between turns. The control failing for an unrelated reason (daily allowance) means no matched comparison is possible, and per the directive no model is blamed by association.
